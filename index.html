    Deliverance platform manual¶

    Welcome to the manual of Deliverance Platform, the platform that brings the management of an organization's robots and IoT devices together in a single panel, whatever the manufacturer of each device.

    This manual covers Platform 0.9.2 and API 0.11.2 (November 2026). The changes since the previous edition are in What's new.

    This manual has three parts:

    • Introduction

      What the platform is, the basic concepts worth knowing and how to get started.

      Start here

    • User guide

      How to use each screen of the platform from the browser: Dashboard, Devices, Monitor, Operation, Workflows, Analytics, User Settings and Admin.

      Go to the guide

    • API reference

      Documentation of the REST API for integrating by code: authentication, available endpoints and explanation of the fields.

      Go to the reference

    Where do I start?¶

    If you are... Start with
    A user who will work with the platform day to day Getting started, then the User guide
    An administrator setting up robots and automations Operation and Workflows
    A developer who wants to integrate by code API reference and Authentication
