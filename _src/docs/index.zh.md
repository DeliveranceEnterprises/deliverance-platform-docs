# Deliverance 平台手册 {#deliverance-platform-manual}

欢迎阅读 **Deliverance Platform** 手册。该平台将组织的机器人和 IoT 设备集中在同一个面板中管理，
与各设备的制造商无关。

本手册对应 **Platform 0.9.2** 和 **API 0.11.2**（2026 年 11 月）。相对于上一版的变化见
[新增内容](introduccion/novedades.md)。

本手册分为三个部分：

<div class="grid cards" markdown>

- **简介**

    平台是什么、需要了解的基本概念以及如何开始。

    [从这里开始](introduccion/que-es-deliverance.md)

- **使用指南**

    如何在浏览器中使用平台的每个页面：仪表板（Dashboard）、设备（Devices）、
    监控（Monitor）、运行（Operation）、工作流（Workflows）、分析（Analytics）、用户设置（User Settings）和管理（Admin）。

    [前往指南](guia-de-uso/login.md)

- **API 参考**

    用于通过代码集成的 REST API 文档：身份验证、可用端点和字段说明。

    [前往参考](referencia-api/introduccion.md)

</div>
