# Deliverance platform manual

Welcome to the manual of **Deliverance Platform**, the platform that brings the management
of an organization's robots and IoT devices together in a single panel, whatever the
manufacturer of each device.

This manual covers **Platform 0.9.2** and **API 0.11.2** (November 2026). The changes since
the previous edition are in [What's new](introduccion/novedades.md).

This manual has three parts:

<div class="grid cards" markdown>

- **Introduction**

    What the platform is, the basic concepts worth knowing and how to get started.

    [Start here](introduccion/que-es-deliverance.md)

- **User guide**

    How to use each screen of the platform from the browser: Dashboard, Devices,
    Monitor, Operation, Workflows, Analytics, User Settings and Admin.

    [Go to the guide](guia-de-uso/login.md)

- **API reference**

    Documentation of the REST API for integrating by code: authentication, available
    endpoints and explanation of the fields.

    [Go to the reference](referencia-api/introduccion.md)

</div>
