# 什么是 Deliverance Platform？ {#what-is-deliverance-platform}

Deliverance Platform 将组织的机器人和 IoT 设备（机器人、传感器、摄像头和电表）集中在同一个面板中管理，与各设备的制造商无关。

在平台上可以启用和整理设备、实时监控其运行、向机器人下达任务、用工作流实现自动化、查询使用和能耗分析，以及管理用户和组织。

## 关键概念 {#key-concepts}

在阅读手册其余部分之前，建议先了解以下概念，它们几乎出现在每一页：

- **组织**：设备和用户所属的实体（客户、场所、部门）。平台支持多个组织以及它们之间的层级关系（层级）。
- **管理员**：带有 *超级用户*（*Superuser*）标记的用户。管理其所属组织及该组织的下级组织，绝不管理其他组织。
- **等级**（**Tier**）：组织签约的级别：*Watch*、*Operate* 或 *Orchestrate*。
- **设备**：在平台上登记的任何机器人、IoT 设备或传感器。分为三类：**机器人**（**Robot**）、**IoT** 和 **传感器**（**Sensor**）；摄像头属于传感器。
- **连接器**：将平台与某一制造商的设备连接起来的组件。如果故障出在连接器，平台会标明 *连接器错误*（*Connector error*）。
- **任务**：机器人执行的一项作业（清洁、配送等），有自己的状态、历史和指标。
- **工作流**：一种自动化：当某个事件发生，并且满足某些条件时，机器人会收到一项任务。
- **事件**：已发生并被记录的事情：任务结束、机器人断开连接、告警等。
- **场景**：设备运行的位置（建筑和楼层）。机器人可以显示在其地图上。
